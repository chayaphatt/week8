# Week 8 Assignment - E-Commerce Clothing Store 

## About This Assignment

เป็นการพัฒนาเว็บแอปพลิเคชันร้านค้าเสื้อผ้าออนไลน์:
* **HTML5 & Modern CSS Layouts:** การจัดวางโครงสร้างเว็บและการตกแต่งด้วยโทนสีเอิร์ธโทนเข้มขรึม พร้อมกล่องข้อความหัวข้อสไตล์คอนทราสต์
* **JSON Data Integration:** การดึงข้อมูลรายการสินค้า แบบไดนามิกผ่านไฟล์ `cloth.json` เพื่อจำลองระบบฐานข้อมูลสินค้าจริง
* **Advanced UI/UX Polish & Interactivity:** การออกแบบการ์ดสินค้า พร้อมเงาลอยตัว, ป้ายปักแสดงสถานะสินค้า, และเอฟเฟกต์ซูมภาพแบบ Smooth Zoom เมื่อนำเมาส์ไปชี้ 

---

## Key Features & Functionality 

* **Mid-Century Modern Aesthetic:** ดีไซน์ภาพรวมที่ใช้โทนสีเข้มหรูหรา ตัดกับกล่องหัวข้อคลาสสิกและขอบมนละมุนตา สร้างเลเยอร์และมิติความลึกให้กับหน้าเว็บอย่างลงตัว
* **Dynamic Product Rendering:** ระบบแสดงผลรายการสินค้าอัตโนมัติที่อ้างอิงข้อมูลจากไฟล์ `cloth.json`
* **Interactive Product Cards:** การ์ดสินค้าพร้อมภาพถ่ายที่จัดวางอย่างพอดีด้วย `object-fit: cover`, ป้ายสถานะสินค้าสุดพรีเมียม และแอนิเมชันขยายภาพอย่างนุ่มนวลเมื่อผู้ใช้เลื่อนเมาส์มาบรรจบ
* **Clean & Focused Layout:** ตัดทอนส่วนเกินที่ไม่จำเป็นออก เพื่อให้ผู้เข้าชมโฟกัสไปที่คอลเลกชันสินค้าแฟชั่นได้อย่างเต็มตาและสบายตา

---

## Technical Stack

* **HTML5:** โครงสร้างหลักของหน้าเว็บไซต์ร้านค้า
* **CSS3:** ออกแบบสไตล์ เลย์เอาต์ โทนสีเข้มขรึม และแอนิเมชันโต้ตอบ 
* **JavaScript (`shopping.js`):** ควบคุมการดึงข้อมูลสินค้าจาก `cloth.json` และเรนเดอร์ลงสู่หน้า DOM
* **JSON (`cloth.json`):** จัดเก็บชุดข้อมูลสินค้าและรูปภาพ
* **GitHub Pages:** สำหรับเผยแพร่และแสดงผลเว็บไซต์ออนไลน์
